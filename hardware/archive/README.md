# Older ESP32 placement

`esp32-layout-v1.kicad_pcb` is the layout that was current before `hardware/esp32/peeple.kicad_pcb`.

Both boards use the same schematic and the same 93 reference designators. The nets match. The outline here is 100 × 61 mm. The current board is 103 × 61 mm. Five parts moved between them: AE1, C14, C15, L2, and U4. Nothing on this board is a part the current layout dropped.

`esp32-layout-v1.kicad_pro` is the KiCad project that went with this placement. Open `hardware/esp32/peeple.kicad_pro` for the board to order.
