# Screen pictures

Pictures of the pager screens. What the firmware does on each screen is [docs/firmware-app.md](../../docs/firmware-app.md).

- `Inbox.png`, `Outbox.png`, `Keyboard.png` are those screens.
- `New beep popup.png` is a page arriving.
- `Compose/` is select, sending, success, and retry.
- `Tracking/` is the locate result: facing arrows, found, and denied.
