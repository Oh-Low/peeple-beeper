# pcbv2 plots

Generated files for the board in `hardware/esp32/`. What to upload, and the order options, are in [docs/esp32-fab.md](../../docs/esp32-fab.md).

Export from `peeple.kicad_pcb` into this folder when you are ready to order. Git ignores the zip, the exploded gerbers, the STEP, the assembly PDF, and the centroid CSVs.
